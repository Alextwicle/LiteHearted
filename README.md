# LiteHearted
This is the official github page for the litehearted minecraft modpack, this exists mainly to let people browse through the code and to keep us organized

Any of the code within here is (unless stated otherwise) is allowed to be used in your own projects

Do note, that this github only contains the code exclusive to litehearted (not the entire modpack) for copyright reasons
